1.2 bisect库函数

  • bisect_left = “左边插” → 插入到相同元素的左侧
  • bisect_right = “右边插” → 插入到相同元素的右侧
    如果查询目标不在数组中，则二者一致

时间复杂度：O(log n)
空间复杂度：O(1)
要求：输入列表必须是已排序的

【例题】34.在排序数组中查找元素的第一个和最后一个位置
给你一个按照非递减顺序排列的整数数组 nums，和一个目标值 target。请你找出给定目标值在数组中的开始位置和结束位置。
如果数组中不存在目标值 target，返回 [-1, -1]。

示例 :

输入: nums = [5,7,7,8,8,10], target = 8
输出: [3,4]

总结选择指南

需求 使用哪个 不存在
统计等于某值的元素个数 right - left 0
找第一个 ≥ x 的元素索引 bisect_left n
找最后一个 < x 的元素索引 bisect_left - 1 -1
找第一个 > x 的元素索引 bisect_right n
找最后一个 ≤ x 的元素索引 bisect_right - 1 -1

【注】库函数常用参数（这里以 bisect_left 为例）

返回值：返回一个索引位置，表示将 x 插入到 a 中并保持有序时，最靠左的插入点。

  • 如果 x 已存在于列表中，返回的是第一个等于 x 的元素的索引（左侧插入点）。
  • 如果所有元素都 < x，返回 len(a)。
  • 如果所有元素都 > x，返回 0。
参数 类型 是否必须 说明
nums list 必须 已排序的可变升序序列。如果是降序列表，结果会出错。
target any 必须 要插入的元素。需要能与 nums 中的元素进行 < 比较。
lo int 可选 搜索范围的左边界（包含），默认为 0。
hi int 可选 搜索范围的右边界（不包含），默认为 len(nums)。
key callable 可选 一个单参数函数，用于从每个元素中提取比较键。常用 lambda 表达式。默认为 None，即直接比较元素本身。
